# 桌面端运营统计与隐私边界

状态：已接入百度统计桌面端匿名事件统计。

## 目标

统计 SuperPoE2 的功能使用情况和版本运营指标，帮助判断查价、集市、构筑编辑和装备仓库等功能的使用率。统计默认开启，用户可以在全局设置中关闭。

## 上报方式

- 只在 Electron 桌面端加载百度统计脚本；官网不复用桌面端事件代码。
- Electron 主进程只为该站点的 `hm.js`/`hm.gif` 请求补固定的官网 Referer，使绑定域名的站点 ID 能在 `app://localhost` 中工作；不会携带构筑页面地址。
- 业务代码只能调用 `src/engine/analytics.ts` 中的 `trackAnalytics`。
- `AnalyticsEvent` 是封闭枚举，不接受任意字符串、对象或用户输入。
- 统计异常、网络失败或百度服务不可用时，不得影响应用启动和业务操作。

## 允许的业务事件

事件只表示固定动作，例如应用启动、登录结果、构筑导入/打开/保存、页面进入和装备仓库/交易中心等功能视图。事件参数不得扩展为构筑或账号数据。

## 禁止上报

以下内容永远不能传给百度统计或任何运营统计接口：

- PoB Code、XML、构筑名称、构筑配置和天赋数据；
- 游戏复制的原始装备文本、装备词缀、技能内容和装备仓库数据；
- 用户名、显示名、邮箱、账号 ID、登录令牌和会话信息；
- 交易站 Cookie、POESESSID、市场挂单详情和私有 URL。

## 百度可能自动收集的基础维度

百度统计服务可能从网络请求获得 IP、系统/浏览器类型、来源页面和时间等基础运营维度。这些维度不由 SuperPoE 业务参数构造，也不与 SuperPoE 账号绑定。应用页面标题和虚拟页面路径必须保持为固定值，不能拼入构筑名、用户名或邮箱。

## 维护要求

新增运营指标时，只能新增不含业务内容的固定事件名，并在本文件同步记录。禁止为了“方便分析”把整个状态对象、路由查询参数、错误原文或表单值传入统计函数。
