# 查价器本地化词缀解析

查价器把游戏剪贴板文本转换为 PoB 可识别的英文原始格式。翻译目录由
`pipeline:translations` 从 PoeCharm2 同步，不能通过修改上游 PoB Lua 文件来补词缀。

## 解析规则

1. 先查精确翻译，再按带参数的模板反向匹配。
2. 交易接口返回的 `extended.hashes` 是词缀身份的权威来源。遇到 `????`、替换字符或其它占位描述时，按 stat ID 回查官方交易目录；CN 目录用于展示，Global 目录用于 PoB canonical English 文本。
3. 官方目录加载后会注册运行时翻译，供游戏剪贴板、查价条件、集市详情和收藏流程共用。不存在按词缀名称维护的别名表，也不应通过添加单个中文映射修复问题。
4. 只有能安全转换成 PoB 语法的词缀才写入查询原文。
5. 未识别的本地化行不会静默伪装成相似词缀，也不会阻止其它已识别词缀继续查价；查价窗口会显示原文诊断。
6. 如果一件装备没有任何可识别词缀，仍然阻止查询并提示用户。

## 数据来源优先级

- 词缀身份和固定选项：官方交易 stat catalog 与 `extended.hashes`。
- PoB canonical 文本：Global 官方 stat catalog。
- 用户可见本地化文本：当前 realm 的官方 stat catalog，随后才是 PoB 翻译目录的模板匹配。
- 无 stat ID 的纯游戏剪贴板行：使用 PoB 翻译模板；无法唯一确认时保留原文诊断，不猜测映射。

## 覆盖率审计

执行 `npm run verify:translations` 可比较 PoB `stat_descriptions.lua` 与本地翻译目录，列出缺失模板和重复键。该审计默认只报告，不会因为上游存在未翻译模板而阻断开发构建；发布或更新翻译时可使用 `--strict`。
