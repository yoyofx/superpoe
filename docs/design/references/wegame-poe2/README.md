## 用途

此目录用于分析 WeGame PoE2 构筑页的布局、切图方式、尺寸和视觉层级，不属于应用运行时资源，也没有接入 `public/` 或构建产物。

资源按页面原始文件名保存：

- `assets/page-bg-*`：全页面场景背景。
- `assets/bd-bg-*`、`bd-logo-*`：构筑总览主背景和标题标识。
- `assets/share-*-bg-*`、`share-*-adorn-*`：纵向可伸缩主框架和上下装饰。
- `assets/equip-bg-*`、`equip-msg-bg-*`：装备纸娃娃区域和装备详情底图。
- `assets/gem-*`、`skill-*`、`buff-*`：技能、辅助宝石和增益区域。
- `assets/tab-*`、`line-adorn-*`、`profile-line-*`：标签状态和分隔装饰。
- `styles/`：与当前页面状态相关的压缩 CSS，仅用于反查资源尺寸和组合关系。
- `source-manifest.json`：下载文件与原始 URL 的对应关系。

## 视觉结构

页面主要通过多层位图组合形成风格，不是依靠复杂 CSS 特效：

1. 冷色场景图作为全屏背景，并覆盖深色遮罩保证内容可读。
2. 主内容区由顶部、中部可重复区域和底部三段式框架组成。
3. 面板内部使用低对比黑褐底色，边缘使用旧金属和雕刻纹理。
4. 当前标签、按钮和标题使用独立透明 PNG，不使用普通圆角矩形。
5. 装备、技能和属性保持高密度三栏布局，装饰只承担分区和层级表达。

## 在 SuperPoE 中的建议

- 复用其三栏信息架构、面板比例、装饰层级和内容密度。
- 正式界面优先使用 PoB/PoE2 上游已有资源，缺少的框架按相同视觉语言重新制作。
- 不要直接把这些参考文件移动到 `public/` 或作为产品资源发布，除非已经确认相应授权。
- 不依赖 WeGame CDN 作为运行时资源地址，避免跨域、失效和版本漂移。
